# Essential Scala — Exercises

Exercises and studies based on the **Essential Scala** book. A hands-on walk through Scala fundamentals: expressions, objects, algebraic data types, collections, and type classes.

![sbt](https://img.shields.io/badge/sbt-build-1f7a5a?style=flat-square)

## 🛠️ Built With
- Scala
- sbt

## 🚀 Run
```bash
sbt compile
sbt run
```
